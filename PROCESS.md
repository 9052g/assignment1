# Process

## Tools used
I used ChatGPT, VS Code, Git and GitHub for this assignment.
- ChatGPT: brainstorming additional argument angles, polishing English phrasing, and expanding the essay structure from a short draft to full length.
- VS Code: editing the markdown files for README and PROCESS.
- Git and GitHub: version control, commit history, and hosting the public repository.

## Content I kept
One thing AI produced that I kept was the framing of **the gap between describing and specifying**. It connected my personal Schotter project experience to a broader design principle, and matched the essay prompt’s direction perfectly. It helped turn a single personal example into a general argument about why programming literacy matters for designers, instead of just talking about my own work.

## Content I rejected
One thing AI produced that I rejected was a generic paragraph claiming that "AI can never replace human creativity and designers will always be needed".
It sounded correct on the surface but was completely empty: it had no specific examples, did not address the actual question of why we should learn to code when machines can write it, and just repeated a common cliché. It was too vague and defensive, so I replaced it with more specific points about reading and evaluating AI output, understanding code as a creative medium, and authorship over digital work.
